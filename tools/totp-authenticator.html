Frequently asked questions

What is TOTP?

TOTP (RFC 6238) produces a 6-digit code that changes every 30 seconds, based on a shared secret and the current time.

Is the code computed locally?

Yes. The code is derived on your device from the secret and the current time; nothing is uploaded.

Where do I get the secret?

From the service you are securing (e.g. its two-factor setup page). Paste the Base32 secret to begin.
