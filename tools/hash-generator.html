Frequently asked questions

Which algorithms are supported?

SHA-256, SHA-384, SHA-512 (via Web Crypto), plus legacy SHA-1 and MD5 for compatibility.

Is it computed locally?

Yes. Every hash is computed in your browser; the input text is not uploaded.

What is a hash used for?

Hashes verify that data has not changed — e.g. confirming a downloaded file matches the publisher's checksum.
